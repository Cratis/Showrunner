title: Frontend proxies
description: The @cratis/showrunner.boxoffice package - the generated TypeScript proxies for the product's commands and queries.
---

`@cratis/showrunner.boxoffice` is the TypeScript side of `Cratis.Showrunner.BoxOffice`: the proxies Arc generates for its commands and queries. It has no components.

```shell
yarn add @cratis/showrunner.boxoffice @cratis/arc @cratis/arc.react @cratis/fundamentals
```

`@cratis/arc`, `@cratis/arc.react` and `@cratis/fundamentals` are peer dependencies. Use the package version that matches the `Cratis.Showrunner.BoxOffice` NuGet package: both are released together.

| Proxy | What it is for |
| --- | --- |
| `AssignSeat`, `ReleaseSeat` | Give a person a seat and take it back; see [Seat licensing](./seats.md). |
| `CurrentRoster` | Who holds the tenant's seats, for the product's maintainers; returns a `SeatRoster`. |
| `Mine` | Where the signed-in user stands with the tenant's seats; returns a `SeatStanding`. |
| `CurrentStanding` | Whether the tenant is suspended and why it is read-only; returns a `TenantStanding`. See [Suspension](./suspension.md). |
| `SetComputeBudget`, `SetComputeConcurrencyLimit` | Limit what a tenant may use of a meter; see [Compute admission](./compute-admission.md). |
| `CurrentLimits` | The tenant's budgets and concurrency limits, for the product's maintainers; returns `ComputeLimits`. |
| `CurrentEntitlements` | What the signed-in user's tenant may do in one answer: whether it is read-only and why, whether it is on a trial and until when, its seats and each module's access; returns an `EntitlementSummary`. |
| `CurrentUsage` | Where the tenant stands with each meter in the allowance period it is in, for the product's maintainers; returns `MeterStanding` values. See [Compute admission](./compute-admission.md). |
| `LinkToPortal` | A signed link that opens the operator's customer portal; returns a `PortalLink`. See [The customer portal](./portal.md). |
| `OnSale` | The offers the operator sells that are not withdrawn; returns `Offer` values. |

The proxies are generated by a Debug build of `Cratis.Showrunner.BoxOffice` into `Source/JavaScript/BoxOffice` and committed; the build workflow fails when they are stale. Never edit them by hand.
